# Day 05 — Linked List + Recursion

## LeetCode Problems

1. **Palindrome Linked List — #234**
   - Approach: Find the middle, reverse the second half, then compare.
   - Time: O(n)
   - Space: O(1)

2. **Fibonacci Number — #509**
   - Approach: Basic recursion with base cases n = 0 and n = 1.
   - Time: O(2^n)
   - Space: O(n) recursion stack

3. **Swap Nodes in Pairs — #24**
   - Approach: Recursively swap each adjacent pair.
   - Time: O(n)
   - Space: O(n) recursion stack
