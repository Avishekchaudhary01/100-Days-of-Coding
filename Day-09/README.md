# Day 09 — Sorting Algorithms

## Problems / Practice

1. **Bubble Sort**
   - Approach: Repeatedly swap adjacent elements when they are out of order.
   - Time: O(n²) worst/average, O(n) best with early stopping
   - Space: O(1)

2. **Selection Sort**
   - Approach: Select the minimum element from the unsorted part and place it at the current position.
   - Time: O(n²)
   - Space: O(1)

3. **Insertion Sort**
   - Approach: Insert each element into its correct position in the already sorted left portion.
   - Time: O(n²) worst/average, O(n) best
   - Space: O(1)
